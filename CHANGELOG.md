# What's new in Shrimpl

## Unreleased

### New

- **App options in every web app.** Open it with Ctrl+, from the app icon's menu, or from the
  context menu, to switch Desktop site, Context menu and Block ads without leaving the app. Shrimpl
  remembers what you choose.
- **Ad blocking.** Choose Standard or Strict for any web app. Ads and trackers are blocked, empty ad
  spaces are hidden, ad popups are closed, and most "turn off your ad blocker" messages go away.
  Shrimpl keeps the block lists up to date for you.
- **Changes without rebuilding.** Site layout, Context menu, Ad blocking, Run in background and Pause in
  battery saver now reach a web app the next time you switch to it. When a change does need a
  rebuild, Save asks first.
- **A new context menu.** Right-click or long press a link or image for a menu in your device's colors
  and style, with App options at the top. On empty space it offers App options alone.

- **What's new.** After an update, Shrimpl shows what changed, once.

### Changed

- Web apps use your device's Material You colors for their menus and dialogs.
- Uninstalling asks once, and lets you keep the app in Shrimpl's list to reinstall later.
- "Link and image menu" is now called Context menu, and new web apps use Shrimpl's menu.
- Site layout is Desktop or Mobile. New web apps start with the one that suits your screen.

### Fixed

- Only Shrimpl can use its connection to Shevery.
- After Shrimpl updates, web apps are always built with the newest template.
